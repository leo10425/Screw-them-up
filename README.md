# Screw them up

Low-poly 模拟经营游戏 · Windows 封装版

欢迎来到这条热闹又“黑心”的小吃街。在这里，你就是那条街上最会算账的摊主——经营摊位、招揽顾客、与隔壁 NPC 摊贩抢生意，在规则边缘试探，把小吃街变成你的提款机。

> 注意：本游戏内容均为虚构，仅供娱乐，请勿在现实生活中模仿任何不当经营行为。

## 下载

- 版本：v0.3.0
- 平台：Windows
- 下载地址：https://github.com/leo10425/Screw-them-up/releases/download/v0.3.0/Screw.them.up.zip

## 运行方式

1. 下载 `Screw.them.up.zip`
2. 解压到任意文件夹
3. 双击其中的可执行文件（`.exe`）启动游戏

## 玩法简介

- 经营摊位：定价、进货、招揽顾客
- 顾客 AI：每位顾客有独立的口味、预算与耐心
- NPC 摊贩：隔壁摊主会和你抢生意
- 灰色策略：在规则边缘试探，赚取更多利润（风险自负）
